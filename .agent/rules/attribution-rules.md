# Attribution Rules

SQLTogether is adapted from [PyTogether](https://github.com/SJRiz/pytogether) by **Syed Jawad Rizvi**, licensed under the MIT License.

These rules ensure proper attribution is maintained throughout all development phases.

## Rule 1: Preserve PyTogether Credit

The following files must always credit PyTogether:

- **README.md** — Must contain an attribution section mentioning PyTogether, linking to the original repo, and naming the original author.
- **NOTICE.md** — Must state that this project is based on PyTogether by Syed Jawad Rizvi, with a link to the original repository.
- **LICENSE** — Must preserve the original copyright line: `Copyright (c) 2025 Syed Jawad Rizvi`.

## Rule 2: Preserve the MIT License Notice

The MIT License requires that the copyright notice and permission notice be included in all copies or substantial portions of the software.

- Do not remove, modify, or obscure the original MIT license text.
- Do not change the original copyright year or author name.
- SQLTogether contributions should add a **separate** copyright line (e.g., `Copyright (c) 2026 SQLTogether contributors`) — do not replace the original.

## Rule 3: Do Not Remove Original Copyright

The `LICENSE` file currently contains:

```
Copyright (c) 2025 Syed Jawad Rizvi
```

This line must remain. Any SQLTogether-specific copyright should be added as an additional line, not a replacement.

## Rule 4: Do Not Present SQLTogether as Official PyTogether

SQLTogether is an **independent adaptation**, not an official version of PyTogether.

- Do not use PyTogether branding (logo, domain, social handles) as if they belong to SQLTogether.
- Do not claim endorsement by the original PyTogether author unless explicitly granted.
- Make it clear in the README that SQLTogether is a separate project.

The README already contains this language:

> SQLTogether is not the official PyTogether project and is not affiliated with or endorsed by the original PyTogether author unless stated otherwise.

This language must be preserved.

## Rule 5: Keep Attribution in README, NOTICE, and LICENSE

When making changes to these files:

- **README.md** — You may update the content to reflect SQLTogether's features and direction, but the Attribution section must remain.
- **NOTICE.md** — Do not delete this file. Keep it accurate.
- **LICENSE** — Do not modify the license terms or remove the original copyright.

## What This Means in Practice

- When rebranding UI text from "PyTogether" to "SQLTogether" (Phase 1), do NOT touch the Attribution section of the README, the NOTICE file, or the LICENSE file.
- When updating docs, always keep a reference to the original project.
- If creating new pages (e.g., About page), include an attribution note if the page describes the project's origin.
